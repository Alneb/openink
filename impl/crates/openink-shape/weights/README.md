# openink-shape weights

`docs/scripts/train_shape.py` from `shape-dataset` output (docs/SHAPE-ENGINE.md). The training data includes
Google's Quick, Draw! dataset (CC BY 4.0): https://github.com/googlecreativelab/quickdraw-dataset
